What is this?  click to expand

This is the control surface for an AX.25 packet network simulator. Define a network of nodes, ports and links below; click Apply & restart to bring it up. Each port becomes one samoyed-direwolf child process exposing a KISS TCP port your AX.25 application connects to. The router moves audio between ports through an FM capture-effect mixer — no real radios involved.

Two ways to edit the same network

  • Form tab — dropdowns, add/remove buttons. Rebuilds the YAML on save (comments are not preserved).
  • Raw YAML tab — direct text editing. Useful for paste/diff, bulk edits, or comments that survive across saves.

Both tabs read and write the same file: {{.ConfigPath}}.

TNC backend

Each port runs its own TNC child process. Two backends are supported:

  • samoyed (default) — a Go port of Dire Wolf. Audio reaches the router via UDP datagrams, which is direct and clean.
  • direwolf — stock Dire Wolf 1.8. No UDP audio output yet, so we tunnel TX audio through ALSA's file plugin into a named pipe per port. Same modem flags as samoyed.

Mixed configs (some ports samoyed, some direwolf) are fine — the on-air signal is identical for both, link compatibility is decided by modem only.
